# SiteForge — 건설 견적·관리 시뮬레이터

건설 프로젝트의 비용 견적, 현장 진행 관리, 자재 주문을 다루는 웹 시뮬레이터입니다.
클라이언트 단독으로 동작하며(브라우저 localStorage 저장), 서버가 필요 없습니다.

> ⚠️ **가상 시뮬레이션 안내**: 본 앱은 교육·시연용 시뮬레이션입니다. 실제 투자·자금 이동·실제 시공이 아니며, 모든 화폐는 가상 크레딧입니다. 18세 이상 이용 권장.

## 주요 기능

- **견적 작성**: 자재·인건비 단가 카탈로그로 항목을 쌓고, 간접비·예비비·마진·세금을 반영한 총액을 자동 산출.
- **프로젝트 진행 관리**: 공정(부지정리·기초·구조·외피·설비·마감)별 가중 진행률과 완료 가치(earned value), 일정 대비 진척 표시.
- **현장 음성 로그**: 마이크로 일일 로그를 녹음하고 긴급도 점수로 우선순위 반영.
- **자재 주문**: 수요에 따라 가격이 변하는 자재를 가상 크레딧으로 주문하고 배송 타이머 표시.
- **현장 노트 / 가상 미리보기**: 로그·활동이 노트로 쌓이고, 평균 긴급도가 가상 시공 미리보기에 반영.

## 실행

정적 파일이므로 아무 정적 서버로 열면 됩니다.

```bash
cd p14-construction-app
python3 -m http.server 8000
# http://localhost:8000
```

## 파일 구성

- `index.html` — 화면 구조
- `style.css` — 스타일(골드 톤, 8px 그리드)
- `script.js` — 견적/프로젝트/자재/노트 로직
- `lung-surprise-eye.js` — 음성 로그 긴급도 산출 보조 엔진
- `manifest.json`, `sw.js` — PWA 매니페스트·서비스워커 스텁

## 문법 체크

```bash
node --check script.js
```
